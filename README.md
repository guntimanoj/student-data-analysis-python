Student performance data analysis using python, pandas, and matplotlib with statistical summaries and visualizations.
# Student Data Analysis (Python)

## Description
A simple Python project that analyzes student performance data and visualizes trends.

## Tools Used
- Python
- pandas
- matplotlib

## Features
- Creates and processes student datasets
- Calculates total and average marks
- Computes subject-wise averages
- Visualizes results using bar charts

## Learning Outcomes
- Data manipulation with pandas
- Basic data visualization with matplotlib
- Working with tabular datasets
